# 🛒 FreshMart Dashboard

## 📌 Project Overview
This project is a Store Manager Dashboard built using IBM Cognos Analytics. It helps analyze sales, profit, and inventory performance across multiple outlets.

---

## 🎯 Features
- KPI Tiles (Total Sales, Profit, Stock-outs)
- Sales by Category Chart
- Top 5 Outlets by Revenue
- Category-wise Sales Distribution
- Inventory Alert Table
- Filters for Outlet and Date
